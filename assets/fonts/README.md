# Newsreader

Source: https://github.com/google/fonts/tree/main/ofl/newsreader

Downloaded from the official Google Fonts repository. Licensed under the SIL Open Font License in `OFL.txt`.

This site's `Newsreader.ttf` is a static instance (weight 450, optical size 48) and a subset for its English interface, generated with fontTools. The website's sans-serif text uses the visitor's system font. No font service is contacted when viewing the site.
