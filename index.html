Read the contribution guide

  1. Build in your project repository

    Keep a separate repository for each group project. Use main for stable work and dev for development. Include your README and the evidence your assignment requires.

  2. Submit a project listing

    Fork the course website repository. Add a listing with your group, project description, source link, and the exact commit you are submitting. Include a demo link if you have one.

    Download project template

  3. Open a pull request for review

    Send your listing to this website's main branch. An instructor or TA reviews it before publication. A listing does not replace assignment submission requirements.
